# Barış Can Yonel - Portfolyo

Modern, responsive ve SEO uyumlu kişisel portfolyo sitesi. Tokat web tasarım ve internet sitesi oluşturma hizmetlerini tanıtan profesyonel tek sayfa (one-page) site.

## Özellikler

- **Responsive Tasarım** – Mobil, tablet ve masaüstü uyumlu
- **SEO Optimizasyonu** – Meta etiketleri, Open Graph, Twitter Cards, Schema.org
- **Tek Sayfa Navigasyon** – Smooth scroll ile bölümler arası geçiş
- **Modern UI** – Accordion, slider, lazy loading
- **İletişim Formu** – Formspree entegrasyonu ile mail gönderimi
- **Sitemap & Robots** – Arama motoru indeksleme desteği

## Teknolojiler

- HTML5, CSS3, JavaScript
- jQuery, Slick Slider, Light Gallery
- Bootstrap, Font Awesome
- Formspree (form işleme)

## Bölümler

- Ana Sayfa (Hero)
- Hakkımızda (accordion)
- Özgeçmiş
- Projeler (portfolio grid)
- Referanslar (testimonials slider)
- Blog & SEO
- İletişim Formu

## Backlink Neden Düşük Görünüyor?

**Backlink** = Başka sitelerin **sizin sitenize** verdiği linklerdir. Sizin sitede Polat Mermer, Yonel Oto, Balsan Papel, Tokat Sigorta vb. linkleri **dışarı veriyorsunuz** (outbound); bu, sizin backlink sayınızı artırmaz.

**Backlink puanını yükseltmek için:**
- Referans sitelerin (polatmermer.com, yonelotoyedekparca.com, balsanpapel.com, tokatsigorta.com) **sizin sitenize** link vermesi gerekir (örn. footer’da “Web tasarım: [Barış Can Yonel](https://www.bariscanyonel.com)”).
- Müşterilerden bu linki eklemelerini rica edin; böylece gerçek **gelen backlink** oluşur.
- Ek olarak: Google İşletmem, LinkedIn/Marketplace, yerel dizinler ve blog konuk yazıları da backlink kaynağı olabilir.

## Kurulum

```bash
# Repoyu klonlayın
git clone https://github.com/barisyonel/Portfolio-.git
cd Portfolio-

# index.html veya index3.html dosyasını tarayıcıda açın
# Veya yerel sunucu kullanın
npx serve .
```

## Vercel ile Deploy

1. [Vercel](https://vercel.com) hesabınıza giriş yapın
2. "Import Project" → GitHub repo: `barisyonel/Portfolio-` seçin
3. Root Directory varsayılan bırakın
4. Deploy
